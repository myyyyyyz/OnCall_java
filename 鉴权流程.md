## 3. 鉴权流程详解

### 3.1 用户登录（获取 Token）

```
客户端                          AuthController                      JwtTokenProvider
  │                                  │                                    │
  │──POST /api/auth/login──────────▶│                                    │
  │  {username, password}            │                                    │
  │                                  │                                    │
  │                                  │──1. 认证 (AuthenticationManager)──▶│
  │                                  │   验证用户名密码 (BCrypt)          │
  │                                  │                                    │
  │                                  │◀──2. 返回 UserDetails─────────────│
  │                                  │                                    │
  │                                  │──3. 生成 Token───────────────────▶│
  │                                  │   generateAccessToken()            │
  │                                  │   generateRefreshToken()           │
  │                                  │                                    │
  │◀──4. 返回 Token─────────────────│                                    │
  │  {accessToken, refreshToken,     │                                    │
  │   user: {id, username, roles}}   │                                    │
```

**代码位置：** `AuthController.login()`

```java
@PostMapping("/login")
public ResponseEntity<Map<String, Object>> login(@RequestBody AuthRequest authRequest) {
    // 1. 认证（验证用户名密码）
    Authentication authentication = authenticationManager.authenticate(
        new UsernamePasswordAuthenticationToken(
            authRequest.getUsername(),
            authRequest.getPassword()
        )
    );
    
    // 2. 加载用户信息
    UserDetails userDetails = (UserDetails) authentication.getPrincipal();
    User user = userService.getUserByUsername(authRequest.getUsername());
    
    // 3. 获取角色列表
    List<String> roles = userDetails.getAuthorities().stream()
        .map(authority -> authority.getAuthority())
        .toList();
    
    // 4. 生成 JWT Token
    String accessToken = jwtTokenProvider.generateAccessToken(userDetails, user.getId(), roles);
    String refreshToken = jwtTokenProvider.generateRefreshToken(userDetails);
    
    // 5. 返回 Token 和用户信息
    return ResponseEntity.ok(response);
}
```

### 3.2 JWT Token 结构

```
eyJhbGciOiJIUzI1NiJ9.              ← Header (算法：HS256)
eyJjcmVhdGVkIjoxNzc0MzQ3ODAyNjMxLC   ← Payload (用户信息)
  "roles": ["ROLE_ADMIN"],           ← 角色列表
  "userId": 5,                       ← 用户 ID
  "sub": "testadmin",                ← 用户名
  "iat": 1774347802,                 ← 签发时间
  "exp": 1774348702                  ← 过期时间 (15 分钟)
.HF9IEM-LFeRjyBE973DQE_8SVVflPbFNnGyeYZUg4ug  ← Signature (签名)
```

**Token 生成代码：** `JwtTokenProvider.generateAccessToken()`

```java
public String generateAccessToken(UserDetails userDetails, Long userId, List<String> roles) {
    Map<String, Object> claims = new HashMap<>();
    claims.put("userId", userId);      // 用户 ID
    claims.put("roles", roles);        // 角色列表
    claims.put("created", new Date()); // 创建时间
    
    return createToken(claims, userDetails.getUsername(), jwtConfig.getExpiration());
}
```

### 3.3 访问受保护接口（JWT 验证）

```
客户端                    JwtAuthenticationFilter              SecurityContext
  │                              │                                    │
  │──GET /api/test/auth─────────▶│                                    │
  │  Authorization: Bearer       │                                    │
  │                              │                                    │
  │                              │──1. 提取 Token────────────────────▶│
  │                              │   getJwtFromRequest()              │
  │                              │                                    │
  │                              │──2. 验证 Token 有效性─────────────▶│
  │                              │   isTokenValid()                   │
  │                              │   - 验证签名                        │
  │                              │   - 检查过期                        │
  │                              │   - 检查黑名单 (Redis)              │
  │                              │                                    │
  │                              │──3. 提取用户信息──────────────────▶│
  │                              │   getUsernameFromToken()           │
  │                              │   getRolesFromToken()              │
  │                              │                                    │
  │                              │──4. 设置 SecurityContext──────────▶│
  │                              │   SecurityContextHolder.setAuth()  │
  │                              │                                    │
  │                              │──5. 继续过滤器链──────────────────▶│
```

**代码位置：** `JwtAuthenticationFilter.doFilterInternal()`

```java
@Override
protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response,
                                FilterChain filterChain) throws ServletException, IOException {
    try {
        // 1. 从 Header 提取 Token
        String jwt = getJwtFromRequest(request); // "Bearer xxx" -> "xxx"
        
        if (StringUtils.hasText(jwt) && jwtTokenProvider.isTokenValid(jwt)) {
            // 2. 验证 Token 有效
            
            // 3. 提取用户信息
            String username = jwtTokenProvider.getUsernameFromToken(jwt);
            List<String> roles = jwtTokenProvider.getRolesFromToken(jwt);
            
            // 4. 加载 UserDetails
            UserDetails userDetails = userDetailsService.loadUserByUsername(username);
            
            // 5. 设置认证信息到 SecurityContext
            UsernamePasswordAuthenticationToken authentication =
                new UsernamePasswordAuthenticationToken(
                    userDetails,
                    null,
                    userDetails.getAuthorities()
                );
            SecurityContextHolder.getContext().setAuthentication(authentication);
        }
    } catch (Exception ex) {
        logger.error("无法设置用户认证信息：{}", ex.getMessage());
    }
    
    // 6. 继续执行后续过滤器
    filterChain.doFilter(request, response);
}
```

### 3.4 方法级角色鉴权（@PreAuthorize）

```
JwtAuthenticationFilter         AuthorizationFilter            TestController
        │                              │                              │
        │◀──SecurityContext 已设置────│                              │
        │    (用户 + 角色信息)          │                              │
        │                              │                              │
        │─────────────────────────────▶│                              │
        │                              │──检查 @PreAuthorize 注解─────▶│
        │                              │   hasAnyRole('USER',         │
        │                              │            'OPERATOR',       │
        │                              │            'ADMIN')          │
        │                              │                              │
        │                              │──验证用户角色────────────────▶│
        │                              │   当前用户：ROLE_ADMIN ✓     │
        │                              │                              │
        │                              │──允许访问───────────────────▶│
        │                              │                              │
        │◀─────────────────────────────│──执行方法───────────────────▶│
        │  {"code":200,                │   return ok()                │
        │   "message":"成功"}          │                              │
```

**常用鉴权注解：**

| 注解 | 说明 | 示例 |
|------|------|------|
| `@PreAuthorize("hasRole('ADMIN')")` | 需要 ADMIN 角色 | 管理员接口 |
| `@PreAuthorize("hasAnyRole('USER','ADMIN')")` | 需要任一角色 | 普通用户或管理员 |
| `@PreAuthorize("isAuthenticated()")` | 需要认证 | 任何登录用户 |
| `@PreAuthorize("permitAll()")` | 允许所有 | 公开接口 |

**代码示例：**

```java
@GetMapping("/auth")
@PreAuthorize("hasAnyRole('USER', 'OPERATOR', 'ADMIN')")
public ResponseEntity<Map<String, Object>> authEndpoint() {
    return ResponseEntity.ok(response);
}

@GetMapping("/admin")
@PreAuthorize("hasRole('ADMIN')")
public ResponseEntity<Map<String, Object>> adminEndpoint() {
    return ResponseEntity.ok(response);
}
```

### 3.5 登出（Token 黑名单）

```
客户端                      AuthController                      RedisService
  │                              │                                    │
  │──POST /api/auth/logout──────▶│                                    │
  │  Authorization: Bearer       │                                    │
  │                              │                                    │
  │                              │──1. 提取 Token────────────────────▶│
  │                              │                                    │
  │                              │──2. 加入黑名单───────────────────▶│
  │                              │   redis.set("token:blacklist:xxx", │
  │                              │              "blacklisted",        │
  │                              │              15, MINUTES)          │
  │                              │                                    │
  │                              │──3. 清除 SecurityContext──────────▶│
  │                              │   SecurityContextHolder.clear()    │
  │                              │                                    │
  │◀──4. 登出成功────────────────│                                    │
```

**代码位置：** `AuthController.logout()`

```java
@PostMapping("/logout")
public ResponseEntity<Map<String, Object>> logout(
        @RequestHeader(value = AUTHORIZATION_HEADER, required = false) String authorization) {
    if (authorization != null && authorization.startsWith("Bearer ")) {
        String accessToken = authorization.substring(7);
        
        // 将 Token 加入黑名单（Redis 存储）
        String blacklistKey = TOKEN_BLACKLIST_PREFIX + accessToken;
        redisService.set(blacklistKey, "blacklisted", 15, TimeUnit.MINUTES);
    }
    
    // 清除 SecurityContext
    SecurityContextHolder.clearContext();
    
    return ResponseEntity.ok(response);
}
```

## 5. 数据库设计

### 5.1 用户表 (user)

```sql
CREATE TABLE `user` (
    `id` BIGINT NOT NULL AUTO_INCREMENT COMMENT '唯一自增主键 id',
    `username` VARCHAR(50) NOT NULL COMMENT '用户名',
    `password` VARCHAR(255) NOT NULL COMMENT '密码（BCrypt 加密）',
    `phone` VARCHAR(20) DEFAULT NULL COMMENT '手机号',
    `user_type` VARCHAR(20) NOT NULL DEFAULT 'user' COMMENT '用户类型：user, operator, admin',
    `create_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `update_time` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (`id`),
    UNIQUE KEY `uk_username` (`username`),
    UNIQUE KEY `uk_phone` (`phone`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='用户表';
```

### 5.2 安全日志表 (security_logs) - 可选

```sql
CREATE TABLE `security_logs` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT,
    `user_id` BIGINT,
    `username` VARCHAR(50),
    `action` VARCHAR(50) NOT NULL,
    `resource` VARCHAR(255),
    `risk_level` VARCHAR(20),
    `result` VARCHAR(20) NOT NULL,
    `ip_address` VARCHAR(50),
    `user_agent` VARCHAR(500),
    `request_params` TEXT,
    `error_message` TEXT,
    `created_at` TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX `idx_username` (`username`),
    INDEX `idx_action` (`action`),
```

### 6.2 SecurityConfig.java

```java
@Bean
public SecurityFilterChain securityFilterChain(HttpSecurity http) throws Exception {
    http
        .csrf(AbstractHttpConfigurer::disable)  // 禁用 CSRF
        .cors(cors -> cors.configurationSource(corsConfigurationSource()))
        .authorizeHttpRequests(auth -> auth
            .requestMatchers(SecurityConstants.PUBLIC_PATHS).permitAll()
            .anyRequest().authenticated()
        )
        .sessionManagement(session -> session
            .sessionCreationPolicy(SessionCreationPolicy.STATELESS)
        )
        .authenticationProvider(authenticationProvider())
        .addFilterBefore(jwtAuthenticationFilter, UsernamePasswordAuthenticationFilter.class);
    
    return http.build();
}
```

### 8.2 前端集成示例 (JavaScript)

```javascript
// 登录
async function login(username, password) {
  const response = await fetch('/api/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ username, password })
  });
  
  const data = await response.json();
  if (data.code === 200) {
    // 保存 Token 到 localStorage
    localStorage.setItem('accessToken', data.data.accessToken);
    localStorage.setItem('refreshToken', data.data.refreshToken);
  }
  return data;
}

// 访问受保护接口
async function fetchProtectedData() {
  const token = localStorage.getItem('accessToken');
  const response = await fetch('/api/test/auth', {
    headers: { 'Authorization': `Bearer ${token}` }
  });
  
  if (response.status === 401) {
    // Token 过期，刷新或重新登录
    await refreshToken();
  }
  
  return response.json();
}

// 刷新 Token
async function refreshToken() {
  const refreshToken = localStorage.getItem('refreshToken');
  const response = await fetch('/api/auth/refresh', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ refreshToken })
  });
  
  const data = await response.json();
  if (data.code === 200) {
    localStorage.setItem('accessToken', data.data.accessToken);
    localStorage.setItem('refreshToken', data.data.refreshToken);
  }
}

// 登出
function logout() {
  const token = localStorage.getItem('accessToken');
  fetch('/api/auth/logout', {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${token}` }
  }).then(() => {
    localStorage.removeItem('accessToken');
    localStorage.removeItem('refreshToken');
    window.location.href = '/login';
  });
}
```

## 9. 安全建议

### 9.1 生产环境建议

1. **JWT 密钥**：使用环境变量 `SECURITY_JWT_SECRET`，不要硬编码
2. **HTTPS**：生产环境必须启用 HTTPS
3. **密码策略**：强制密码复杂度要求（长度、大小写、特殊字符）
4. **限流保护**：登录接口增加限流（如 5 次/分钟）
5. **账户锁定**：连续失败多次后锁定账户
6. **日志审计**：定期审查安全日志，发现异常行为
7. **Token 黑名单**：登出时将 Token 加入 Redis 黑名单

### 9.2 Token 有效期建议

| Token 类型 | 有效期 | 用途 |
|-----------|--------|------|
| Access Token | 15 分钟 | 访问 API 接口 |
| Refresh Token | 7 天 | 刷新 Access Token |

### 9.3 角色权限设计

| 角色 | 权限范围 | 示例接口 |
|------|----------|----------|
| `ROLE_ADMIN` | 全部权限 | 配置修改、用户删除 |
| `ROLE_OPERATOR` | 常规操作 | 文件上传、对话查询 |
| `ROLE_USER` | 基础查询 | 对话接口 |

## 10. 常见问题

### Q1: Token 过期如何处理？

**A:** 使用 Refresh Token 刷新 Access Token，或重新登录。

### Q2: 如何禁用某个用户的访问权限？

**A:** 
1. 将用户标记为禁用（数据库 `enabled=false`）
2. 或将该用户的所有 Token 加入黑名单

### Q3: 如何记录用户操作日志？

**A:** 使用 `SecurityLogService` 记录所有鉴权相关操作。

### Q4: 中文用户名登录失败？

**A:** 确保请求头设置 `Content-Type: application/json; charset=utf-8`。
